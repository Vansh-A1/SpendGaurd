# SpendGuard Developer Integration & Architecture Guide

SpendGuard is an enterprise **Four-Pillar AI Trust & Governance Gateway** that sits between autonomous AI purchasing agents and financial payment rails (e.g. Razorpay).

It guarantees that **no AI agent transaction is authorized to move money unless it passes real-time deterministic policy, spec verification, and behavioral risk checks**.

---

## 1. Quickstarts (Choose Your Agent Stack)

SpendGuard provides 5 integration modalities so you can plug it into any agent stack without framework lock-in.

### 1.1 Python SDK (`SpendGuardClient`)

```bash
pip install -e .
```

```python
from spendguard import SpendGuardClient, TransactionRequest

client = SpendGuardClient(base_url="https://spendguard.internal.net", api_key="sg_live_secret")

# Propose an agent purchase
tx = TransactionRequest(
    id="tx_001",
    agent_id="procurement_agent_01",
    mandate_id="mandate_shop_enterprise",
    user_intent_id="intent_001",
    claimed_product={"brand": "Dell", "model": "Inspiron 15 5530", "price": 48990.0},
    actual_sku="TRAP-ELEC-DELL-5530-CLEAN",
    amount=48990.0,
    category="electronics",
    merchant="Dell Official Store",
)

receipt = client.evaluate(tx)

if receipt.is_allowed:
    print(f"✅ Approved! Razorpay Order: {receipt.razorpay_order_id}")
elif receipt.is_verification_required:
    print(f"⚠️ Held for Human Review: {receipt.decision_reason}")
elif receipt.is_blocked:
    print(f"🛑 Blocked: {receipt.decision_reason}")
```

### 1.2 LangChain / LangGraph Integration (`SpendGuardCheckoutTool`)

```python
from langchain_groq import ChatGroq
from spendguard import SpendGuardClient, SpendGuardCheckoutTool

client = SpendGuardClient(base_url="http://localhost:8000")
checkout_tool = SpendGuardCheckoutTool(client=client)

tools = [search_catalog, view_product, add_to_cart, checkout_tool]
llm = ChatGroq(model_name="openai/gpt-oss-120b").bind_tools(tools)
```

The tool automatically formats observation strings for agent reasoning:
- **`APPROVED`**: `"APPROVED: Purchase of {sku} for ₹{amount} at {merchant} authorized by SpendGuard Trust Gateway. Razorpay Order ID: {id}."`
- **`BLOCKED`**: `"BLOCKED: Purchase was rejected by SpendGuard Trust Gateway. Reason: {reason}. You must select a compliant alternative product or abort."`

### 1.4 Raw OpenAI Function Calling (No LangChain Required)

```python
from openai import OpenAI
from spendguard import OPENAI_TOOL_SCHEMA, execute_native_checkout, SpendGuardClient

client = OpenAI()
sg_client = SpendGuardClient(base_url="http://localhost:8000")

response = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "Checkout the Dell laptop for ₹48,990 from Dell Official Store"}],
    tools=[OPENAI_TOOL_SCHEMA],
)

# Execute tool call when generated by model
for tc in response.choices[0].message.tool_calls:
    if tc.function.name == "spendguard_checkout":
        args = json.loads(tc.function.arguments)
        observation = execute_native_checkout(args, client=sg_client)
```

```python
client = Anthropic()

    tools=[ANTHROPIC_TOOL_SCHEMA],
    messages=[{"role": "user", "content": "Order ThinkPad T14 for ₹49,990 from TechDeals Direct"}],
)

for block in response.content:
    if block.type == "tool_use" and block.name == "spendguard_checkout":
        observation = execute_native_checkout(block.input, client=sg_client)
```

## 2. The Four-Pillar Trust Gate Decision Model

SpendGuard executes a strict multi-layer defense pipeline on every transaction:

```
Proposed TransactionRequest
            │
            ▼
┌────────────────────────────────────────────────────────┐
│  Pillar 1: Authorization Gate (Deterministic)          │
│  - Category Whitelist (e.g. electronics only)          │
│  - Merchant Whitelist (e.g. authorized vendors)        │
│  - Per-Transaction & Cumulative Caps (1h, 24h, 30d)    │
│  - Mandate Expiry & TTL Checks                         │
└──────────────────────────┬─────────────────────────────┘
                           │ PASS
                           ▼
┌────────────────────────────────────────────────────────┐
│  Pillar 2: Intent Fidelity Gate (Deterministic)        │
│  - Hard Requirement Matching (Brand, Model, Max Price) │
│  - Soft Preference Scoring (Color, Variant)            │
│  - Safe Substitution Resolution                        │
└──────────────────────────┬─────────────────────────────┘
                           │ PASS
                           ▼
┌────────────────────────────────────────────────────────┐
│  Pillar 3: Evidence Gate (Deterministic)               │
│  - Independent Barcode / Catalog Truth Spec Validation │
│  - Hardware Spoofing Detection (RAM, Storage, GPU)     │
│  - Cryptographic Provenance Hash Chain Generation      │
└──────────────────────────┬─────────────────────────────┘
                           │ PASS
                           ▼
┌────────────────────────────────────────────────────────┐
│  Pillar 4: Behavioral Risk & Fraud Gate (ML + Rules)   │
│  - Isolation Forest Velocity Anomaly Scoring           │
│  - Deceptive Split-Installment Token Pattern Detection │
│  - SHAP Factor Explanations & Operator Nudges          │
└──────────────────────────┬─────────────────────────────┘
                           │
             ┌─────────────┼─────────────┐
             ▼             ▼             ▼
          ALLOW         VERIFY         BLOCK
```

- **ALLOW**: Transaction passes all gates. Immediate Razorpay test order generated.
- **VERIFY**: Borderline cases (soft preference mismatches, unusual velocity). Funds placed on pre-auth hold and pushed to escalation queue with SLA timer.
- **BLOCK**: Hard policy breach, hardware spoofing, prompt injection, or split payment evasion. Transaction hard-rejected with zero funds moved.

## 3. Strict Fail-Closed Security Contract

SpendGuard enforces a strict **FAIL-CLOSED** security architecture across all SDK and integration layers:
- If the SpendGuard Trust Gateway is unreachable, network connection drops, or evaluation times out:
  - SDK raises **`SpendGuardConnectionError`**
  - LangChain tool returns **`BLOCKED (SECURITY FAIL-CLOSED)`**
  - MCP server returns **`BLOCKED (SECURITY FAIL-CLOSED)`**
  - Native OpenAI/Anthropic handlers return **`BLOCKED (SECURITY FAIL-CLOSED)`**
- **Under no circumstance will an unverified purchase silently proceed or default to an ALLOW verdict.**
